# 🌞 Solar Panel Fault Classification using Deep Learning

A professional deep learning project that classifies solar panel conditions using images and a Streamlit web application.

## 🔍 Fault Categories
- Bird Drop
- Clean
- Dusty
- Electrical Damage
- Physical Damage
- Snow Covered

## 🚀 Features
- CNN-based image classification using TensorFlow/Keras
- Streamlit web app with professional UI
- Solar panel background theme
- Confidence score with green progress bar
- Image upload & real-time prediction
- Downloadable prediction results

## 🧠 Model
- Input size: 224 × 224
- Framework: TensorFlow / Keras
- Saved format: TensorFlow SavedModel
- Optimized for low-resource systems (8GB RAM)

## 🖥️ Web Application
The Streamlit app allows users to upload a solar panel image and instantly get:
- Predicted fault class
- Confidence score
